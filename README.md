## 🚀 Featured Projects

### 01 — Nova E-Commerce

A modern e-commerce experience built with Next.js, featuring product search, detailed product pages, cart functionality, responsive design, and persistent client-side interactions.

**Tech:** Next.js · TypeScript · Tailwind CSS · daisyUI

### 02 — Weather App

A responsive weather application that retrieves real-time weather information using the Open-Meteo API. The interface includes city search, dynamic weather backgrounds, loading states, error handling, and responsive UI.

**Tech:** Next.js · TypeScript · Tailwind CSS · daisyUI · Open-Meteo API

### 03 — Focus Timer

A clean Pomodoro-style productivity timer built with Next.js. The application includes a 25-minute countdown, start, pause, reset controls, and completed session tracking.

**Tech:** Next.js · React · TypeScript · Tailwind CSS · daisyUI

### 04 — Todo Kanban

A responsive Kanban task manager built with vanilla JavaScript. It allows users to create, organize, complete, and remove tasks while keeping task data persistent with LocalStorage.

**Tech:** HTML · CSS · JavaScript · LocalStorage

### 05 — Expense Tracker

A modern expense management application for adding expenses, calculating total spending, searching by name, sorting by amount, and keeping data persistent using LocalStorage.

**Tech:** HTML · CSS · JavaScript · LocalStorage · DOM

### 06 — Password Generator

A responsive password generator that allows users to customize password length and character types, with password strength feedback and one-click clipboard copying.

**Tech:** HTML · CSS · JavaScript · Clipboard API
